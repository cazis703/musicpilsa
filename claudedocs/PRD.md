# PRD: 위로의 문장 (Healing Sentence Typing)

## 1. 개요

### 프로젝트 목적
지친 하루를 보낸 사용자가 위로가 되는 한글 문장을 따라 입력하며, 경쟁이나 압박 없이 잔잔한 시각·청각적 몰입 속에서 마음의 여유를 되찾을 수 있는 힐링 웹 경험을 제공한다.

### 타겟 사용자
- 업무·학업 중 짧은 휴식 시간에 부담 없이 몰입할 수 있는 콘텐츠를 찾는 직장인 및 학생
- 등수, 시간 제한, 게임오버 같은 경쟁 요소에 지쳐 있고, 조용히 집중할 수 있는 활동을 원하는 사용자
- ASMR, 힐링 영상, 로파이 음악 등 잔잔한 무드 콘텐츠를 즐겨 찾는 사용자

### 핵심 가치 제안
등수도, 시간 제한도, 실패도 없다. 화면에 떠오르는 위로의 문장을 자신의 속도로 따라 적으며, 손끝에서 반짝이는 빛과 잔잔한 배경 영상·음악에 둘러싸여 잠시 숨을 고를 수 있다.

---

## 2. 기능 요구사항

### 기능 1: 위로 문장 따라 쓰기

**사용자 스토리**
> 지친 마음을 달래고 싶은 사용자로서, 화면에 뜨는 위로의 문장을 내 속도로 따라 입력하고 싶다, 압박감 없이 문장 하나하나에 집중하며 위안을 얻기 위해

**수용 기준**
- [ ] 화면에는 항상 하나의 위로 문장만 표시되며, 사용자가 문장의 마지막 글자까지 정확히 입력하면 1초 이내에 다음 문장으로 자동 전환된다.
- [ ] 표시되는 문장은 20~60자 내외의 한글 위로 문장 목록(부록 A)에서 제공되며, 같은 문장이 연속 2회 반복되지 않는다.
- [ ] 사용자가 잘못된 글자를 입력해도 게임이 종료되거나 문장이 초기화되지 않으며, 해당 글자만 오타로 표시된 뒤 올바른 글자를 다시 입력하면 진행이 이어진다.
- [ ] 화면 어디에도 타이머, 카운트다운, 제한시간, 순위, 게임오버 문구가 존재하지 않는다.
- [ ] 사용자는 언제든 입력을 멈추거나 페이지를 떠날 수 있으며, 이전 진행 상태가 저장되지 않아도 오류 메시지가 발생하지 않는다.
- [ ] 문장 목록이 모두 소진되면 처음 순서(또는 무작위 순서)로 되돌아가 문장 제공이 끊기지 않는다.

### 기능 2: 타이핑 반짝임·빛 파티클·페이드아웃 이펙트

**사용자 스토리**
> 위로 문장을 입력하는 사용자로서, 한 글자씩 입력할 때마다 은은하게 반짝이고 빛이 흩날리는 시각적 반응을 보고 싶다, 단순한 타이핑이 아니라 감각적으로 위로받는 느낌을 경험하기 위해

**수용 기준**
- [ ] 사용자가 올바른 글자를 입력하면 해당 글자가 0.3초 내외의 시간 동안 은은한 빛(glow)으로 채워지는 애니메이션과 함께 표시된다.
- [ ] 글자가 채워지는 순간 해당 글자 위치에서 작은 빛 파티클이 사방으로 흩어졌다가 1초 이내에 자연스럽게 사라진다.
- [ ] 이미 입력 완료되어 화면에 남아있는 글자는 입력된 시점으로부터 일정 시간(예: 수 초)이 지나면 서서히 투명해지며 사라지는(fade out) 연출이 적용되고, 사라진 뒤에도 해당 글자가 정상 입력되었다는 판정에는 영향을 주지 않는다.
- [ ] 오타를 입력했을 때는 반짝임·파티클 효과 대신 그 글자만 눈에 띄되 자극적이지 않은 방식(예: 옅은 붉은 밑줄 등)으로 구분되어 표시된다.
- [ ] 사용자가 빠르게 연속으로 타이핑해도 이펙트가 밀리거나 겹쳐서 화면이 끊기는 것처럼 보이지 않고 매 글자마다 독립적으로 자연스럽게 재생된다.
- [ ] 저사양 환경 등으로 이펙트가 정상적으로 렌더링되지 않는 경우에도 문장 입력 진행 자체(글자 판정)에는 영향을 주지 않는다.

### 기능 3: 다크 무드 배경 + 로컬 영상·음악 재생

**사용자 스토리**
> 힐링 콘텐츠를 즐기는 사용자로서, 어두운 톤의 화면 위로 은은한 불빛이 떠다니고 잔잔한 영상과 음악이 함께 흐르는 분위기 속에서 타이핑하고 싶다, 시각적·청각적으로 편안하게 몰입하기 위해

**수용 기준**
- [ ] 게임 화면 전체 배경은 어두운 톤을 기본으로 하며, 크기와 밝기가 서로 다른 은은한 빛/파티클 요소가 화면 전체에서 천천히 떠다니는 것처럼 보인다.
- [ ] 준비된 배경 영상 파일이 존재하는 경우, 화면 진입 후 3초 이내에 해당 영상이 재생되기 시작하며 자동으로 반복 재생된다.
- [ ] 준비된 배경 음악 파일이 존재하는 경우 영상과 함께 자동 재생되고, 사용자는 화면 내 컨트롤로 음소거·음량 조절을 할 수 있다.
- [ ] 배경 영상·음악 파일이 아직 준비되어 있지 않거나 로드에 실패한 경우, 화면이 빈 채로 멈추지 않고 기본 다크 배경(떠다니는 불빛 연출)과 안내 문구("배경 영상을 준비 중입니다" 등)로 자연스럽게 대체된다.
- [ ] 배경 영상과 떠다니는 불빛 연출이 함께 표시되어도 문장 텍스트와 입력 글자는 배경과 뚜렷하게 구분되는 밝기·대비로 항상 읽을 수 있다.
- [ ] 배경 영상·음악의 로드 지연이나 재생 실패가 발생해도 문장 타이핑 기능(기능 1, 기능 2)의 동작에는 영향을 주지 않는다.

## 3. 비기능 요구사항

### 성능
- 사용자의 키 입력은 100ms 이내에 화면(글자 채움, 반짝임 시작)에 반영되어 타이핑 흐름이 끊기지 않아야 한다.
- 반짝임, 빛 파티클, 페이드아웃 등 모든 타이핑 이펙트는 초당 약 60프레임 수준으로 끊김 없이 동작하는 것을 목표로 하며, 이펙트가 문장 표시나 입력 판정의 지연을 유발하지 않아야 한다.
- 배경 영상은 화면 진입 후 3초 이내에 재생을 시작해야 하며, 초과 시 기능 3의 대체 화면 기준이 적용된다.

### 보안
- 회원가입, 로그인, 개인정보 입력이 없으므로 사용자 인증 관련 보안 요건은 MVP 범위에서 해당 없음.
- 외부 API 호출이나 인증키 사용이 없어 관련 보안 위험이 존재하지 않는다.

### 접근성
- 데스크톱 브라우저의 표준 키보드 입력을 기본 지원한다.
- 어두운 배경 위에 표시되는 문장·입력 텍스트는 배경 밝기와 무관하게 읽을 수 있는 대비를 유지한다.
- 화면 크기(데스크톱 기준 최소 1024px 너비)에서 문장 표시 영역과 배경 연출이 잘리지 않고 표시된다.

## 4. 제약사항

### 기술적 제약
- 배경 영상(mp4)과 배경 음악(mp3/wav)은 외부 API를 통해 스트리밍하지 않으며, 사용자가 직접 준비해 프로젝트 내 정해진 폴더(예: 영상/음악 각각의 로컬 정적 파일 경로)에 넣어 사용하는 방식으로 동작한다.
- 따라서 배경 영상·음악 재생 기능은 네트워크 상태나 외부 서비스 장애의 영향을 받지 않으며, 별도의 API 키나 인증 절차가 필요하지 않다.
- 파일이 아직 해당 경로에 준비되지 않은 초기 상태에서도 앱은 정상적으로 실행되어야 하며, 이 경우 기능 3의 대체 화면(기본 다크 배경 + 안내 문구)이 노출된다.

### 비즈니스 제약
- MVP 단계에서는 별도 예산이나 외부 유료/무료 API 계약 없이, 로컬에 준비되는 미디어 파일만으로 동작하는 것을 전제로 한다.
- 회원가입, 로그인, 결제 등 계정 관련 기능은 포함하지 않는다.

---

## 5. 성공 지표
- 신규 사용자가 화면 진입 후 첫 문장 입력을 시작하는 비율 90% 이상
- 평균 세션 이용 시간 5분 이상 (문장이 끊기지 않고 이어지며 몰입이 유지되는지 확인)
- 세션당 완료(끝까지 타이핑)하는 문장 수 평균 5개 이상

---

## 향후 확장 (MVP 이후)
- 떨어지는 단어 모드 등 추가 플레이 모드
- 정확도(%), 누적 타수 등 통계 표시 및 저장
- 여러 배경 영상/음악 테마 중 선택 및 전환 기능
- 회원가입/로그인 및 사용자별 데이터 동기화
- 사용자 커스텀 위로 문장 업로드 기능
- 모바일/터치 환경 지원

## 부록 A: 위로 문장 세트

다크 톤 배경과 떠다니는 불빛 무드에 어울리는, 잔잔하고 담백한 위로 문장이다. 각 문장은 20~60자 내외로 구성한다.

1. "오늘 하루도 참 애썼어요. 이제 잠시 모든 걸 내려놓아도 괜찮아요."
2. "괜찮아, 조금 느려도 돼. 삶은 속도가 아니라 방향이니까."
3. "지금 이 순간, 애쓰지 않아도 당신은 이미 충분합니다."
4. "숨을 깊게 들이쉬고, 다시 천천히 내쉬어 보세요."
5. "잘하지 않아도 괜찮아요. 그저 오늘을 살아낸 것만으로도 충분해요."
6. "어두운 밤하늘에도 별은 늘 그 자리에서 빛나고 있어요."
7. "가끔은 아무것도 하지 않는 것이 가장 큰 용기가 됩니다."
8. "당신의 마음속 작은 불빛은 아직 꺼지지 않았어요."
9. "실수해도 괜찮아요. 그것도 결국 나아가는 과정이니까요."
10. "지친 하루의 끝에서, 당신을 조용히 안아주고 싶어요."
11. "혼자라고 느껴지는 밤에도, 누군가는 당신을 생각하고 있어요."
12. "천천히 걸어도 결국 도착한다는 걸 잊지 마세요."
13. "오늘의 눈물은 내일의 단단함이 되어줄 거예요."
14. "완벽하지 않아도 괜찮아요, 당신은 그 자체로 소중하니까."
15. "잠시 멈춰서도 괜찮아요. 쉬는 것도 나아가는 방법입니다."
16. "당신이 견뎌온 시간들은 결코 헛되지 않았습니다."
17. "무너질 것 같은 날에도, 다시 일어설 힘은 당신 안에 있어요."
18. "고요한 밤, 당신의 마음에도 잔잔한 평화가 깃들기를."
19. "누구에게도 말하지 못한 마음까지도 다 괜찮아요."
20. "오늘 하루의 무게를 잠시 내려놓고, 편히 쉬어가세요."

> 문장 수 확장이나 테마별 분류는 향후 확장 범위에서 검토할 수 있다.
