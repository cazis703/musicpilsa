# PRD: 힐링 타이핑 - 효과음 설정 & 배경음악 재생 컨트롤

## 1. 개요

### 프로젝트 목적
위로/격언/긍정/확언 문장을 감성적으로 따라 타이핑하며 힐링하는 경험에, 타이핑 과정 자체의 몰입감과 성취감을 높이는 효과음을 더한다.

### 타겟 사용자
위로가 필요한 순간 감성적인 문장을 따라 타이핑하며 마음을 다스리고 싶은 일반 사용자. 기존 앱 사용자와 동일하며, 이번 기능을 위한 별도의 신규 타겟은 없다.

### 핵심 가치 제안
글자를 입력할 때, 문장을 완성했을 때, 화면 요소를 조작할 때마다 느껴지는 청각적 피드백을 통해 타이핑 순간에 더 몰입하고, 문장을 끝까지 완성했을 때의 성취감을 더 크게 느낄 수 있다. 동시에 소리가 필요 없는 순간에는 완전히 무음으로 전환할 수 있어, 소리가 방해 요소가 되지 않는다. 또한 배경음악을 사용자가 원하는 순간에 직접 멈추고 다시 재생할 수 있어, 소리 전반에 대한 통제감을 더 크게 느낄 수 있다.

## 2. 기능 요구사항

### 기능 1: 효과음 설정

**사용자 스토리**
> 감성적인 타이핑으로 위로받고 싶은 사용자로서, 타이핑 동작과 화면 조작에 어울리는 효과음을 듣고, 그 소리 크기를 배경음악과 별도로 조절하고 싶다, 타이핑에 더 몰입하고 완성의 성취감을 느끼되 필요할 땐 소리 없이 조용히 집중하기 위해.

**하위 요구사항 (효과음 3종)**
1. 타건음: 사용자가 글자를 한 자씩 입력할 때마다 재생되는 소리
2. 문장 완료음: 한 문장을 끝까지 정확하게 입력 완료했을 때 재생되는 소리 (성취감 연출)
3. 버튼/UI 클릭음: 배경 바꾸기, 음악 바꾸기, 테마 전환, 건너뛰기 등 화면의 버튼을 클릭할 때 재생되는 소리

**설정 방식**
- 효과음 전체 크기를 조절하는 전용 볼륨 조절 장치를 배경음악 볼륨 조절과 별도로 제공한다.
- 효과음 종류별 개별 켜기/끄기는 이번 범위에 포함하지 않는다.
- 효과음 볼륨을 최소로 내리면 타건음·완료음·클릭음이 모두 들리지 않는 무음 상태가 된다.
- 효과음 볼륨과 배경음악 볼륨 모두, 사용자가 맞춰둔 값이 페이지를 새로고침하거나 다시 방문해도 그대로 유지된다 (기존에는 배경음악 볼륨도 새로고침 시 초기값으로 돌아갔으나, 이번 기능에서 두 볼륨 모두 유지되도록 개선한다).

**수용 기준**
- [ ] 사용자가 글자를 한 자 입력할 때마다 타건음이 매번 재생된다.
- [ ] 사용자가 한 문장을 처음부터 끝까지 정확하게 입력 완료한 시점에 완료음이 1회 재생된다. 입력 중간에 오탈자가 있어 문장이 완성되지 않은 경우에는 완료음이 재생되지 않는다.
- [ ] 배경 바꾸기, 음악 바꾸기, 테마 전환, 건너뛰기 버튼 중 어느 것을 클릭해도 클릭음이 재생된다.
- [ ] 효과음 전용 볼륨 조절 장치를 조작했을 때, 배경음악의 볼륨은 변하지 않고 효과음의 크기만 조절된다.
- [ ] 효과음 볼륨을 최소(0)로 설정하면 타건음, 완료음, 클릭음이 모두 재생되지 않는다.
- [ ] 효과음 볼륨을 다시 0보다 큰 값으로 올리면 세 가지 효과음이 다시 정상적으로 재생된다.
- [ ] 페이지를 새로고침하거나 다시 방문했을 때도 사용자가 이전에 맞춰둔 효과음 볼륨 값이 유지된 채로 화면에 반영된다.
- [ ] 페이지를 새로고침하거나 다시 방문했을 때도 사용자가 이전에 맞춰둔 배경음악 볼륨 값이 유지된 채로 화면에 반영된다.

### 기능 2: 배경음악 재생/일시정지 컨트롤

**사용자 스토리**
> 감성적인 타이핑으로 위로받고 싶은 사용자로서, 배경음악을 원하는 순간에 직접 멈추고 다시 재생하고 싶다, 소리를 완전히 끄지 않고도 잠깐 조용히 있고 싶을 때 스스로 통제하기 위해.

**하위 요구사항**
1. 화면에 원형 배경의 재생/일시정지 토글 버튼을 배치한다. (참고 디자인: 진회색 원형 버튼 + 흰색 아이콘)
2. 배경음악이 재생 중일 때는 버튼에 일시정지 아이콘(❚❚)이 표시되고, 클릭하면 음악이 멈추고 아이콘이 재생 아이콘(▶)으로 바뀐다.
3. 배경음악이 멈춰 있을 때는 버튼에 재생 아이콘(▶)이 표시되고, 클릭하면 음악이 이어서 재생되고 아이콘이 일시정지 아이콘(❚❚)으로 바뀐다.
4. 이 버튼은 기존의 음소거 버튼(스피커 아이콘)과는 별개의 기능이다 — 음소거는 소리만 끄고 재생은 계속되지만, 이 버튼은 재생 자체를 멈춘다.

**설정 방식**
- 이전/다음 트랙 이동 버튼은 이번 범위에 포함하지 않는다 (기존 "음악 바꾸기" 버튼으로 대체됨).

**수용 기준**
- [ ] 배경음악이 재생 중일 때 버튼을 클릭하면 음악이 즉시 멈추고 버튼 아이콘이 ▶(재생)로 바뀐다.
- [ ] 배경음악이 멈춰 있을 때 버튼을 클릭하면 음악이 즉시(또는 멈췄던 지점부터) 다시 재생되고 버튼 아이콘이 ❚❚(일시정지)로 바뀐다.
- [ ] 페이지 진입 시 자동재생이 정상적으로 시작되면 버튼은 ❚❚(일시정지 가능) 상태로 표시된다.
- [ ] 재생/일시정지 버튼을 조작해도 음소거 여부나 볼륨 값은 변하지 않는다.
- [ ] 음소거 상태에서 재생/일시정지 버튼으로 음악을 멈췄다가 다시 재생해도 음소거 상태가 그대로 유지된다.

## 3. 비기능 요구사항

### 성능
- 글자를 입력하는 시점과 타건음이 재생되는 시점 사이에 사용자가 지연을 체감하지 않아야 한다 (입력과 소리가 즉각적으로 함께 일어나는 것처럼 느껴져야 한다).
- 여러 효과음이 짧은 간격으로 연속 재생되어도(예: 빠른 연속 타이핑) 소리가 끊기거나 겹쳐서 이상하게 들리지 않아야 한다.

### 보안
- 이 기능은 로그인이나 서버 저장을 필요로 하지 않는다. 효과음 설정값은 사용자의 기기 안에서만 다뤄지며, 외부 서버로 전송되거나 다른 사용자와 공유되지 않는다.

### 접근성
- 효과음 볼륨 조절 장치는 기존 배경음악 볼륨 조절 장치와 동일한 방식(위치, 조작 형태)으로 눈에 잘 띄게 배치되어, 처음 사용하는 사용자도 쉽게 찾아 조작할 수 있어야 한다.
- 소리에 민감하거나 조용한 환경에서 사용하는 사용자를 위해 볼륨을 최소로 내리는 조작이 한 번의 간단한 동작으로 가능해야 한다.
- 재생/일시정지 버튼은 현재 상태(재생 중/멈춤)를 아이콘만으로도 명확히 구분할 수 있어야 하며, 스크린 리더 등 보조 기술에서도 현재 상태가 무엇인지 안내되어야 한다.

## 4. 제약사항

### 기술적 제약
- 이번 범위는 효과음 설정, 배경음악 재생/일시정지 컨트롤 두 기능으로 한정하며, 오버레이 UI 통합, 콘텐츠 카탈로그, 디스플레이 커스터마이징 등 다른 개선 아이디어는 포함하지 않는다. 단, 볼륨 값 유지(새로고침 후에도 값이 남아있는 것)는 효과음 볼륨과 배경음악 볼륨 모두에 적용되는 것으로 범위에 포함한다.
- 효과음 종류별 개별 on/off 토글 기능은 이번 범위에 포함하지 않는다 (전체 볼륨 조절로 대체).
- 배경음악 재생 컨트롤에 이전/다음 트랙 이동 버튼은 포함하지 않는다.
- 구체적인 저장·재생 방식은 이 문서에서 다루지 않으며, 별도의 기술 설계 단계에서 결정한다.

### 비즈니스 제약
- 별도 계정/로그인 시스템이 없는 완전 로컬 앱이라는 기존 서비스 성격을 유지한다.

---

## 5. 성공 지표
- 사용자가 효과음을 켠 상태에서 타이핑을 방해받지 않고 문장 완료까지 이어간다 (효과음으로 인한 이탈이나 불편 신고가 없다).
- 효과음 볼륨을 0으로 내려 완전히 무음으로 전환하는 것이 정상적으로 동작한다 (100%의 경우에서 무음이 확인된다).
- 문장 완료음이 문장을 정확히 완성했을 때만 울려, 성취감을 주는 신호로 정확히 기능한다 (오탐/누락 없이 매 완료 시점에 일치하여 재생된다).
- 재생/일시정지 버튼 클릭 시 100%의 경우에서 실제 음악 재생 상태와 버튼에 표시되는 아이콘이 서로 일치한다 (상태 불일치 없음).
